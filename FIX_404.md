# 🔧 Исправление 404 ошибки на Vercel

## Проблема
Получаете 404 ошибку на главной странице: `https://tmataxikz.vercel.app/`

## Решение

### Вариант 1: Настройка в Vercel Dashboard (рекомендуется)

1. Зайдите в **Vercel Dashboard** → ваш проект
2. Перейдите в **Settings** → **General**
3. Проверьте настройки:
   - **Root Directory**: оставьте пустым (`.`)
   - **Framework Preset**: Other
   - **Build Command**: `cd frontend && npm install && npm run build`
   - **Output Directory**: `frontend/build`
   - **Install Command**: оставьте пустым или `npm install`

4. Сохраните и сделайте **Redeploy**

### Вариант 2: Если не помогает

Если проблема сохраняется, попробуйте изменить структуру:

1. В **Settings** → **General**:
   - **Root Directory**: `frontend`
   - **Build Command**: `npm install && npm run build`
   - **Output Directory**: `build`

2. Обновите `vercel.json`:

```json
{
  "rewrites": [
    {
      "source": "/api/(.*)",
      "destination": "/api/index.js"
    },
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

3. Переместите `api` папку в `frontend/api` или создайте отдельный проект для API

### Вариант 3: Проверка сборки

Убедитесь, что сборка прошла успешно:

1. В Vercel Dashboard откройте последний деплой
2. Проверьте логи сборки
3. Убедитесь, что папка `frontend/build` создана
4. Проверьте, что в ней есть `index.html`

### Быстрая проверка

После деплоя проверьте:
- `https://tmataxikz.vercel.app/api/health` - должен вернуть `{"status":"ok"}`
- `https://tmataxikz.vercel.app/` - должна открыться главная страница

## Если ничего не помогает

Создайте новый проект в Vercel с настройками:
- **Root Directory**: `frontend`
- **Build Command**: `npm install && npm run build`
- **Output Directory**: `build`

И добавьте API как отдельный проект или используйте Vercel Serverless Functions напрямую.
